3. Criterios de aceptación
CA1. Pantalla de login

Dado que un usuario abre la plataforma,
 cuando no tiene una sesión autenticada,
 entonces debe visualizar una pantalla de login antes de acceder al perfil de cliente.

CA2. Usuarios autenticados

Dado que existen usuarios registrados,
 cuando el usuario ingresa credenciales válidas,
 entonces el sistema debe autenticarlo y permitirle acceder a la plataforma.

CA3. Usuarios inválidos

Dado que un usuario ingresa credenciales incorrectas,
 cuando intenta iniciar sesión,
 entonces el sistema debe rechazar el acceso y mostrar un mensaje genérico de error.

Importante: mensaje genérico, no decir “usuario no existe” o “contraseña incorrecta”, para no revelar información.

CA4. Registro básico de acceso

Dado que un usuario intenta iniciar sesión,
 cuando el intento finaliza,
 entonces el sistema debe guardar un log con usuario, fecha/hora, resultado y origen básico.

CA5. Usuarios iniciales

Dado que se está implementando la primera versión,
 cuando se inicialice el sistema,
 entonces deben existir al menos 3 usuarios de prueba o usuarios internos configurados.

4. Resultado esperado

La plataforma permite identificar quién está utilizando la herramienta, bloquea el acceso no autenticado y genera un registro básico de intentos de ingreso.

Paso 3. Crear el servicio de autenticación

Archivo:

src/application/services/authentication_service.py

from datetime import datetime

from src.application.ports.access_log_repository import AccessLogRepository
from src.application.ports.password_hasher import PasswordHasher
from src.application.ports.user_repository import UserRepository
from src.domain.access_log import LoginEvent
from src.domain.users import AuthenticatedUser


class AuthenticationError(Exception):
    pass


class AuthenticationService:
    def __init__(
        self,
        user_repository: UserRepository,
        password_hasher: PasswordHasher,
        access_log_repository: AccessLogRepository,
    ) -> None:
        self._user_repository = user_repository
        self._password_hasher = password_hasher
        self._access_log_repository = access_log_repository

    def login(self, username: str, password: str) -> AuthenticatedUser:
        normalized_username = username.strip().lower()
        attempted_at = datetime.now()

        user = self._user_repository.find_by_username(normalized_username)

        if user is None:
            self._register_failed_attempt(
                username=normalized_username,
                attempted_at=attempted_at,
                message="Invalid credentials",
            )
            raise AuthenticationError("Credenciales inválidas.")

        if not user.is_active:
            self._register_failed_attempt(
                username=normalized_username,
                attempted_at=attempted_at,
                message="Inactive user",
            )
            raise AuthenticationError("Credenciales inválidas.")

        password_is_valid = self._password_hasher.verify_password(
            plain_password=password,
            password_hash=user.password_hash,
        )

        if not password_is_valid:
            self._register_failed_attempt(
                username=normalized_username,
                attempted_at=attempted_at,
                message="Invalid credentials",
            )
            raise AuthenticationError("Credenciales inválidas.")

        authenticated_user = AuthenticatedUser(
            username=user.username,
            full_name=user.full_name,
            role=user.role,
            authenticated_at=attempted_at,
        )

        self._access_log_repository.save(
            LoginEvent(
                username=user.username,
                attempted_at=attempted_at,
                success=True,
                message="Login successful",
            )
        )

        return authenticated_user

    def _register_failed_attempt(
        self,
        username: str,
        attempted_at: datetime,
        message: str,
    ) -> None:
        self._access_log_repository.save(
            LoginEvent(
                username=username,
                attempted_at=attempted_at,
                success=False,
                message=message,
            )
        )

Paso 4. Implementar el hasher de contraseñas

Para una demo interna inicial, puedes usar hashlib.pbkdf2_hmac de Python. Para producción, lo ideal sería integrarlo con SSO corporativo, Microsoft Entra ID o el mecanismo definido por Seguridad de la Información.

Archivo:

src/infrastructure/security/pbkdf2_password_hasher.py

import base64
import hashlib
import hmac
import os


class Pbkdf2PasswordHasher:
    def __init__(self, iterations: int = 390_000) -> None:
        self._iterations = iterations

    def hash_password(self, plain_password: str) -> str:
        salt = os.urandom(16)
        password_hash = hashlib.pbkdf2_hmac(
            "sha256",
            plain_password.encode("utf-8"),
            salt,
            self._iterations,
        )

        encoded_salt = base64.b64encode(salt).decode("utf-8")
        encoded_hash = base64.b64encode(password_hash).decode("utf-8")

        return f"pbkdf2_sha256${self._iterations}${encoded_salt}${encoded_hash}"

    def verify_password(self, plain_password: str, password_hash: str) -> bool:
        algorithm, iterations, encoded_salt, encoded_expected_hash = password_hash.split("$")

        if algorithm != "pbkdf2_sha256":
            return False

        salt = base64.b64decode(encoded_salt)
        expected_hash = base64.b64decode(encoded_expected_hash)

        calculated_hash = hashlib.pbkdf2_hmac(
            "sha256",
            plain_password.encode("utf-8"),
            salt,
            int(iterations),
        )

        return hmac.compare_digest(calculated_hash, expected_hash)

                    role=user_data["role"],

import csv

from src.application.ports.access_log_repository import AccessLogRepository
from src.domain.access_log import LoginEvent


class CsvAccessLogRepository(AccessLogRepository):
    def __init__(self, file_path: Path) -> None:
        self._file_path = file_path

    def save(self, event: LoginEvent) -> None:
        file_exists = self._file_path.exists()

        with self._file_path.open("a", newline="", encoding="utf-8") as file:
            writer = csv.DictWriter(
                file,
                fieldnames=[
                    "username",
                    "attempted_at",
                    "success",
                    "message",
                    "source",
                ],
            )

            if not file_exists:
                writer.writeheader()

            writer.writerow(
                {
                    "username": event.username,
                    "attempted_at": event.attempted_at.isoformat(),
                    "success": event.success,
                    "message": event.message,
                    "source": event.source,
                }
            )

from src.application.services.authentication_service import AuthenticationError
from src.bootstrap import build_authentication_service


def render_login_page() -> bool:
    if "authenticated_user" in st.session_state:
        return True

    st.title("Ingreso a Plataforma Perfil de Cliente")
    st.caption("Ingrese sus credenciales para continuar.")

    with st.form("login_form"):
        username = st.text_input("Usuario")
        password = st.text_input("Contraseña", type="password")
        submitted = st.form_submit_button("Ingresar")

    if not submitted:
        return False

    authentication_service = build_authentication_service()

    try:
        authenticated_user = authentication_service.login(
            username=username,
            password=password,
        )
    except AuthenticationError:
        st.error("Credenciales inválidas.")
        return False

    st.session_state["authenticated_user"] = authenticated_user
    st.rerun()

    return True


def render_logout_button() -> None:
    authenticated_user = st.session_state.get("authenticated_user")

    if authenticated_user is None:
        return

    with st.sidebar:
        st.caption(f"Usuario: {authenticated_user.full_name}")
        st.caption(f"Rol: {authenticated_user.role}")

        if st.button("Cerrar sesión"):
            del st.session_state["authenticated_user"]
            st.rerun()

Las contraseñas no están guardadas en texto plano.
El sistema identifica al usuario autenticado en st.session_state.
El sidebar muestra el usuario autenticado.
Existe un botón de cerrar sesión.
Se registra cada intento de login en data/access_log.csv.
La lógica de autenticación no está dentro de app.py.
La lógica queda separada en Domain, Application, Infrastructure y UI.
11. Recomendación importante para tu contexto bancario

Para esta primera historia, JSON y CSV están bien como demo controlada o MVP técnico. Pero para una plataforma interna de cumplimiento, mi recomendación arquitectónica sería evolucionar así:

MVP:
  JSON users + CSV logs

Siguiente versión:
  Tabla de usuarios + tabla de logs en base de datos

Versión corporativa:
  Microsoft Entra ID / SSO + auditoría centralizada


No pondría autenticación casera como solución final si la herramienta va a manejar información sensible de clientes, investigaciones o alertas.

12. Próximo refactor recomendado después de esta historia

Después del login, la siguiente mejora natural sería reemplazar el diccionario gigante de build_customer_profile por objetos más claros. Actualmente profile_service.py devuelve un diccionario con cliente, cuentas, cuentas_firmantes, mensual, consolidado, causas, agencias, transacciones, alertas, ach y kpis.

Algo mejor sería:

@dataclass(frozen=True)
class CustomerProfile:
    customer: Customer
    accounts: list[Account]
    signer_accounts: list[SignerAccount]
    monthly_summary: pd.DataFrame
    consolidated_summary: pd.DataFrame
    transaction_causes: pd.DataFrame
    agencies: pd.DataFrame
    related_transactions: pd.DataFrame
    alerts: pd.DataFrame
    ach_transactions: pd.DataFrame
    kpis: CustomerProfileKpis


Pero no lo haría todavía en esta historia. Primero implementa login, deja una base limpia, y luego migras el perfil por partes.

Resumen ejecutivo

Para esta historia, no metas login dentro de app.py. Crea una miniarquitectura limpia alrededor de autenticación:

Domain:
  User, LoginEvent

Application:
  AuthenticationService

Infrastructure:
  JsonUserRepository, CsvAccessLogRepository, Pbkdf2PasswordHasher

UI:
  Streamlit Login Page


Con esto cumples la historia, mejoras la mantenibilidad y preparas el proyecto para crecer hacia roles, permisos, auditoría formal y eventualmente SSO corporativo.
